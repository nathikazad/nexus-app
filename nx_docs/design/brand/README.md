# NX Docs — Teal pages

Folded pages for writing and connected ideas.

Part of the NX Cards visual family: flat layered geometry, a three-tone palette,
and a dark icon background. Where used, the approved italic Nx is outlined
vector artwork, with no font dependency.

Main color: #237E83. Background: #16282A.

The mark SVG has a transparent background. The icon SVG is an opaque square;
platform rounding is left to the operating system. PNG exports are provided
at 1024, 512, 256, 128, 64, 48, and 32 pixels.

Launcher assets are wired into each existing platform target. After changing
SVGs, run `python3 scripts/generate_app_icons.py` from mobile/.

Regenerate using `python3 ../../../design/brand/generate_family.py` from this folder.
